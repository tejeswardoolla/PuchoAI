Keyboard Shortcut

Use Alt+B (or Command+B on Mac) to toggle the slider on any ordinary webpage.

You can change this shortcut in Chrome at chrome://extensions/shortcuts.

Fullscreen Notes

Chrome prevents floating DOM overlays (like this slider) on pages that are in true fullscreen mode (e.g., YouTube video fullscreen). The slider will still work in browser fullscreen (F11), but if an element requests fullscreen via the Fullscreen API, overlays are restricted for security. If you need assistance during video fullscreen, exit fullscreen first.
